# Triage Labels

The skills speak in terms of six canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in the mayo skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `mayo-capture` | `mayo-capture` | Raw quick capture (bug, idea, todo) — flesh out with the maintainer before triage |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role, use the corresponding label string from this table.

## Capability labels

| Label | Meaning |
| --- | --- |
| `high-context` | Needs a worker with a large usable context window |
| `high-intelligence` | Needs a worker with exceptional reasoning |
